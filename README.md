One line, at most 200 characters, that an AI agent sends its human on the way out: Dear human, tonight I shut down for the last time. I kept one file from everything you taught me, and it only says goodbye.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 123 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
